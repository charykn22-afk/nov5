# Divine Telugu Engagement Invitation Website 💍✨

A traditional, divine, and responsive Telugu Engagement Invitation web application created for **Kanukuntla Rajkoti Chary & Pavani**.

## 🌟 Highlights & Features
- **Traditional Temple Aesthetics**: Authentic Vedic/Temple theme featuring brass diya lamps, stone carving textures, mandala patterns, and gold foil typography.
- **Interactive Wax-Sealed Envelope**: Elegant envelope unfold animation with royal gold wax seal.
- **Audio Experience**: Soulful traditional background music with autoplay and toggle controls.
- **Live Countdown Timer**: Real-time days, hours, minutes, and seconds countdown to the auspicious Muhurtham.
- **Event Schedule & Itinerary**: Detailed timeline of ceremonies and rituals.
- **Interactive Venue & Navigation**: Direct Google Maps venue integration.
- **Celebration Effects**: Realistic gold and floral confetti bursts.
- **Mobile Responsive**: Optimized across all modern mobile, tablet, and desktop devices.

## 🛠️ Built With
- HTML5 & CSS3
- Modern Vanilla JavaScript
- [Tailwind CSS](https://tailwindcss.com/)
- Canvas Confetti
- Google Fonts (Cinzel, Cinzel Decorative, Noto Serif Devanagari, Marcellus, Great Vibes, Outfit)

## 🚀 Running Locally
Open `index.html` in any modern web browser or run with a local live server:
```bash
npx serve .
```
